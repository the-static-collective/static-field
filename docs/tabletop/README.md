## Publishing shelves (proposed)

- **FIELD NOTES — Pocket Games:** small cut-and-play experiments.
- **FIELD CASES — Mysteries at the Table:** evidence-led dinner and paper investigations.
- **FIELD WORLDS — Cooperative Play:** routes, resources, roles and consented world crossings.
- **FIELD FORGE — Games That Make Games:** rule inheritance, source-bound remix and independently accepting tables.

These are editorial imprints, not existing corporate or licensing entities. Static Field preserves the game sources; lemonPRESS is a proposed editorial/printing partner, not a claim that a publishing pipeline is live.

## Source and edition discipline

- The existing Google Drive [TABLETOP GAME LIBRARY — 000 Index & Edition Ledger](https://docs.google.com/document/d/1VPvBXoIHg_aZGHZ-otUWuUt0-cBk_tkkONmZtyaavJs/edit) separately records the two established paper-playable titles; this dossier is an **expanded recovery index** and does not silently upgrade any experimental branch or concept into a finished release.
- Treat **PAPER RULES READY**, **EXECUTABLE EXPERIMENT**, **BROWSER DEMO**, **PROPOSED ADAPTATION**, and **CONVERSATION FOSSIL** as different evidence states. The detailed entry carries the original owner's source, physical translation and outstanding proof work.
- A game card is not authorization to collect data, speak for a partner, bind a person, certify delivery, transfer ownership or make a real-world claim. HOLD and REFUSE remain legitimate table outcomes.
- Before publishing an edition, check source permissions/licenses, build artifacts, accessible print layouts, distinct player/host materials, and a real human playthrough. Record player feedback and revise only with provenance.
