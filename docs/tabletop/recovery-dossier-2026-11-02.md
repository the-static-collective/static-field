# STATIC FIELD
## Tabletop & Paper Arcade — Recovery Dossier
**Edition:** Working 0.1 · **Date:** 2 November 2026 · **Publisher concept:** Static Field × Lemon Press

> **Working dossier, not a release catalog.** We found real printable kits, executable experiments, adaptable systems, and conversation-only designs. Those are different evidence states. Open pull requests are not assumed merged; built prototypes are not assumed field-tested; fictional in-game consent is not real permission.

## The finding

**We are already behaving like an experimental games press.** Three families have emerged: (1) portable paper and case-night games; (2) source-bound co-op worlds and cards; (3) meta-games that make or transmit other games. The print shop ancestry of Static Field makes the bridge to Lemon Press particularly natural. That is an editorial inference, not proof of a commercial release or public adoption.

**Found in this bounded recovery:** 35 named items or grouped lines across 6 shelf categories. Several lines are suites or overlapping carriers, so this is **not** a count of independent finished games.

## Classification / evidence

**Paper rules ready** means instructions/cards exist, not that strangers have successfully played. **Executable** means code was described in source-owned PRs with tests, usually unmerged. **Historically deployed** is a dated deployment claim, not a November 2 availability check. **Adaptation** proposes analog mechanics that have not yet been tested on paper. **Recovered concept** comes from chat or ledger only.

## Publisher architecture — proposed, not implemented

Four imprints let a visitor distinguish an actual boxed game from a provocative tool:

1. **FIELD NOTES — Pocket Games.** 5–20 minute cut-and-play games: Neighbor Experiment, a paper-first Right Hands ruleset, Smoke Signals after design.
2. **FIELD CASES — Mysteries at the Table.** Who Murdered Tomorrow, then Vanishing Carton only after its independent print packet exists.
3. **FIELD WORLDS — Cooperative Play.** Little Yes Express, Wormhole Wars, Grace/Full Measure, selected watershed and resource-cycle adaptations.
4. **FIELD FORGE — Games That Make Games.** Living Deck, Constitute, 009–013 Worldmaker sequence, with strict source lineage.

**Do not falsely reclassify:** TABLE & ROAD is an illustrated reflective deck; THE NEXT TABLE is a host/inheritance protocol; reLATTE / Full Measure represent distinct authority systems, not a single game token ledger.

### Production contract for every new entry

A Static Field game sheet should carry: Registry ID · title · owning project/branch/commit · edition · exact content source · player count and duration (tested or estimated) · physical requirements · setup · turn grammar · end conditions · interruption/refusal rules · printed assets · accessibility notes · offline guarantee · data/privacy limits · what was actually tested · unresolved defects · explicit permission/licensing state · inheritance/translation permission.

### Real-play receipt

Document *table and date*, number of players, observed rules confusion, real duration, whether anyone could decline/stop without penalty, materials actually used, defects, and edition change. Obtain voluntary permission before collecting names or photos. In-game REPORT is not independent CONFIRM, and neither confers rights over other projects.
