# STATIC FIELD

STATIC FIELD is a local-first world runtime for playing ordinary places through accumulated resonance without allowing narrative interpretation to counterfeit historical occurrence.

`WORLDSEED-001` proves one bounded region—**THE PORCH**—with two simultaneous projections over one append-only event history:

- **Surface**: attributable occurrences and ordinary physical state.
- **Resonance**: derived relations that may become strange without promoting themselves into source authority.

The first playable specimen is **STATIC-FIELD-FIRST-BELL-001**. A party enters the Porch, prepares the room, hears two unresolved Bell occurrences, may notice or miss an open-corner relation, may cross into Resonance, may trace one prior relation, receives a knock at the screen door, and closes a receipt while the Bell source remains unresolved.

## Run

```bash
npm install
npm test
npm run typecheck
npm run build
npm run demo:first-bell -- --out ./out/first-bell
npm start
```

The browser server binds to `127.0.0.1` by default and persists canonical events to `var/static-field/history.jsonl`.

## What this proves

- deterministic canonical identity;
- append-only world events;
- deterministic projections;
- Surface/Resonance separation;
- attributable attendance and playable absence;
- derived Field Depth;
- Charge/capacity verbs without moral rank;
- a missable secret;
- relation tracing without meaning promotion;
- unresolved Bell and Knock occurrences;
- detected-but-unopened Crossing residue;
- restart-safe local persistence;
- deterministic CLI receipts;
- a tiny browser surface that cannot edit historical events.

## What this does not prove

WORLDSEED-001 does not implement a giant open world, MMO networking, generalized NPC AI, combat, economy, dream interpretation, theological truth, persistent geolocation, or live adapters to neighboring repositories.

Band Runtime, Static Live, PostEmahh'n, Upper Room, Full Measure, Dogram, Bandcamp/catalog data, and other neighboring systems retain their own authority. STATIC FIELD may later consume typed receipts or adapters from them; it does not silently reimplement their source-of-truth semantics.

> Leave the chair out. Somebody else may still arrive.
