# STATIC FIELD 011 — The World Breeder

**Status: independent, draft, browser-local fictional experiment.** This stacks on the exact `STATIC FIELD` Living World Atlas 010 source, while leaving every existing module, source owner, world constitution, and active public experience unchanged.

## What is genuinely new

010's constellation requires two separate worlds to finish existing challenges. 011 creates a **new rule not present in either source world** from two different, exact-source 009 templates: `CONNECTION × DIGNITY → WORKER_VOICE_PASSAGE` or `CONNECTION × WITNESS → OPEN_LEDGER_ROUTE`. It generates a named child-world with its own fresh original 007 rail inventory via actual 010 `fork`, and adds an independently testable mechanic: **AUDIT + LISTEN before BUILD; explicit RELAY after BUILD**. This prevents a previously allowable native route action until the added prerequisite is met. The child is executable using real 010 and 009 functions (`fork`, `act`, `playVariant`), rather than a fabricated cross-world outcome. The original 009 rule is not mutated; 011's rule stays in an explicit separately replayable overlay.

## Run

Node 20+ (tested on Node 22); zero production dependencies:

```sh
node --test experiments/little-yes-field-008/rail/game.test.mjs experiments/little-yes-field-008/kingdom/kingdom.test.mjs experiments/expansion-forge-009/tests/forge.test.mjs experiments/living-world-atlas-010/tests/atlas.test.mjs experiments/world-breeder-011/tests/breeder.test.mjs
node experiments/world-breeder-011/build.mjs
node experiments/world-breeder-011/proof.mjs
```

`experiments/world-breeder-011/index.html` is a completely self-contained offline browser game (open the single HTML directly). You can nominate a crossing, record each parent's separate YES/REFUSE, birth a new game-only world, play the actual supported 009 native moves and a new relay, inspect source digests, and download/reimport a replay-validated JSON passport. The `Play entire synthetic crossing` button demonstrates a successful six-action execution. No install, network service, game account, blockchain or external source keys.

## Proof gates

- Native original 007, 008, 009, 010 code executed, no copied pseudo-solver.
- Two distinct, independently admitted parents with source-specific templates required; unsupported combinations HOLD.
- Each parent has its own separate local YES; an explicit REFUSE blocks birth, without penalty or world mutation.
- A new child starts from a new native 009/007 inventory. Its provenance refers to both parents in the 011 recipe, without claiming a native dual-parent transfer in the 010 core.
- The new game blocks native BUILD before AUDIT and LISTEN, then records an entirely new optional RELAY operation after native construction.
- A forged parent candidate, modified child inventory, invented consent, erased action events, fake resource authority or fake relay fails review.
- The complete local demonstration is reproducible byte-for-byte across independent executions.

## What is *not* built

This is a deterministic, bounded grammar with exactly two defined supported lens crossings, not arbitrary self-modifying generated programs or a general AI game designer. The modeled tables all run within a single local browser. Hashes prove exact byte integrity, not authorship, identity, human assent, physical performance, real worker rights, labor safety or actual real-world permission. Source cards and accounts from PostEmahh'n have not been verified; parent choices are fictional game actions. No NFT, PENNY issuance, reLATTE signed crossing, actual food or railway construction, production integration or deployment. Playing does not submit anything to Reality 2.0 or update public Static Field. All rights remain with their source owners. Receivers should HOLD until separately authenticating real sender and locally admitting an actual proposal.

A future phase can introduce a source-owned authenticated inter-table courier, independent destination game governance, combined real-world feasibility, and opt-in human verification without violating these boundaries.
