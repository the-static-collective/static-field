# STATIC FIELD 012 — The World Garden

**Review-only source experiment** stacked on `STATIC FIELD 011 WORLD BREEDER`, itself on `010 Living World Atlas → 009 Expansion Forge → 008/007 Little Yes Express`. It does not modify any preceding world, nor connect authenticated real-world people or assets.

## What is genuinely executable

- Creates three independent **original 010 Atlas** fictional worlds using the original **009 Forge** and 007 railway record; uses the original **011 World Breeder** to propose Dignity + Railway and Witness + Railway seed mechanics.
- Distinguishes DORMANT seed proposals, `OBSERVE` and `TEND` local game activities, independent HELD/YES/REFUSE selection, incompatible/unsupported pair HOLD, and exactly one bounded experimental graft.
- On two explicit local YES choices, executes the native 011 `nominate → separate parent YES → birth` functions to create a **new native 010/009/007 playable child world**, never copying the parent inventories.
- New 012 layer requires explicit `ACKNOWLEDGE` of the fictional disputed **42 claimed / 39 observed WOOD** before construction, then the original 011 `AUDIT → LISTEN → BUILD → RELAY` must run to completion. Separate `SHARE` releases a *fictional* blueprint cartridge. No authority is derived from ledger arithmetic.
- Portable SHA-256 content-integrity mail packet (not signed/authenticated) goes to an independently modeled garden. Receiver can HOLD, REFUSE or ADMIT AS FICTIONAL REFERENCE. Import cannot mint a source-owned seed, grant permission, or duplicate resources.
- Every event is replayed from the original initial setup through source native code during `verify` and before any new action. Tampered votes, activities, game inventories, missing events, imports, unfamiliar commands, and invented authority fail closed.
- Zero network calls, cloud credentials, tracking, wallets, paid services or package installation.

```bash

  experiments/little-yes-field-008/kingdom/kingdom.test.mjs \
  experiments/expansion-forge-009/tests/forge.test.mjs \

  experiments/world-garden-012/tests/garden.test.mjs
node experiments/world-garden-012/build.mjs
node experiments/world-garden-012/proof.mjs
```

Open `experiments/world-garden-012/index.html` directly; it's a self-contained no-network HTML with the original native engine code embedded by a deterministic build. Begin from an empty plot or run a full fictional example. Plant two discoveries, nurture them, make each independent Little Yes choice, graft, obey the game mechanics, and optionally export JSON. Use the **Open a different garden** option before importing the packet to see the independent receiver's HOLD/REFUSE choice. You can save and load local replay-verified garden JSON.

## Current limits and explicit next review gates

- Supported graft: 011 **DIGNITY × WITNESS** only. The third original 010 Atlas-derived seed is deliberately held: no proven source-owned native composition port for that pair. The two source seeds share a Railway parent, but the separate owner decisions are synthetic local votes, not two independently authenticated humans. This is a grammar with bounded fixed recipes, not an unrestricted AI invention engine.
- The 012 new rule is a game-only dispute-acknowledgment gate; it is not evidence that 39 or 42 pieces of actual firewood exist. No real rail, worker consent, wage payment, NFT, money, physical materials, legal authority or external world change is credited.
- The receiver only admits an **idea reference**, not a new playable native 011 child or an authentic source card. No real multiplayer yet. A digest confirms packet integrity, not authorship or real-world truth.
- HTML builder correctness, CI proof, and programmatic tests do not replace an actual human party/table and Android phone playtest. Native original source-branch boundaries remain review-only.
