# STATIC FIELD / THE EXPANSION FORGE 009

**Status:** Review-only, local-first, source-owned cooperative expansion composer. New experiment on exact 008 Static Field history. No merge, deployment, blockchain mint, work order, authenticated card, issuer, external participant, real-person consent, physical execution or human witness.

## The game that makes more games

The operator can import an exported record from the original Little Yes Express 007 or the Earth Remembers 008 game. The forge validates the *shape* and fictional boundary of the record, extracts bounded safe event descriptions, and derives three **different rule-set candidates**, with an exact event reference on each. It chooses from six *defined and audited* templates, not arbitrary generated JavaScript:

- **Second Track**: discover and construct a rail connection not present in the prior game's constructed-route list.
- **Hearth Circle**: craft modeled firewood and convene a fictional circle.
- **Night Shift**: audit disputed wood, craft a blueprint, and explicitly hold a fictional listening circle. The original worker refusal is not erased, nor does a new game circle count as actual worker assent.
- **Ledger Day**: hold the disputed 42 vs 39 WOOD finding without issuing stock.
- **Garden Route**: open Cedar–Hearthside and collect synthetic food.
- **Commons Blueprint**: make a game blueprint and an agreed, resource-funded line.

The chosen template's conditions are executed against a **fresh original 007 source-owned game engine**, not simulated with placeholder checkboxes. The conductor offers a specific game move; players may take it, choose a different legal move, or do nothing. Input resources, built rails, approvals, real persons and authority never carry over from another party record. Game victory is an additional, optional fictional objective; it does not alter or overwrite the original 007 victory conditions.

After playing, the locally generated 007 return record can be fed back into the forge to produce another generation. This is a genuine local recursive story-to-rules-to-play-to-story cycle; every round remains local fiction and explicitly selected by the table.

## Launch

`index.html` is self-contained: download and open directly in a modern browser. No account, third-party library, CDN, server, network or key. The forge comes with two source-engine-generated demo episodes. For the actual game flows, open 007 or 008, take one or more meaningful moves, export their JSON game record, and use **Import a party record**.

The **portable expansion cartridge** includes the minimized, allowlisted source history plus candidate and content hash; another party may choose **Receive a portable expansion**, independently regenerate the candidate, and then explicitly select the game. Hashes are *not* signatures or witness attestation. Unlike imported executable mods, packets contain only the finite declarative rule vocabulary and safe strings; no JavaScript, dynamic code or network actions are accepted.

Manual regeneration (Node 20+):

```sh
node experiments/expansion-forge-009/build.mjs
node --test experiments/little-yes-field-008/rail/game.test.mjs \
  experiments/little-yes-field-008/kingdom/kingdom.test.mjs \
  experiments/expansion-forge-009/tests/forge.test.mjs
```

`build.mjs` joins the existing original source engine and the new bounded forge as a single HTML artifact. Check in both the source and compiled artifact when modifying rules; CI checks rebuild parity.

## Real provenance and explicit boundaries

- Owner-native game rules: `experiments/little-yes-field-008/rail/game.mjs` from CANNON 007 as archived by Static Field 008.
- Owner-native worker-voice extension: `experiments/little-yes-field-008/kingdom/kingdom.mjs`, itself executing the 007 engine.
- Living Deck and First Bell: **unaltered**. The original native Static Field Little Yes doorway persists in its own 008 branch.
- All demonstrations and exported game records are synthetically authored/unverified. Anonymous/fake `record` files can claim a game move; *no* cryptographic source identity is established.
- SHA-256 proves only content consistency. It cannot establish provenance, permission, reality, safe engineering, fair pay, or labor assent.
- `SCRIPTED_YES` in the 008 source remains a fictional role state. The 009 `CIRCLE` action represents table listening only. No worker was contacted or certified.
- The `42 WOOD / 39 observed` disagreement always remains disputed. No disputed stock is spent; zero monetary, NFT, Deed or real material credit is issued.
- At most three bounded proposals are offered. New rules are chosen from an explicit allowlist. Users select any local game fork; packets never self-activate.
- User-provided real names, private fields, and unrelated source payloads are not reproduced in the minimized cartridge. Relevant event text from the fictional party source **is** included, so review it before sharing.
- No server calls or external account actions. Local file exports do not modify canonical Static Field state or Full Measure, reLATTE, JAR;VIS, GHoT, GrO, Reality 2.0 or PENNY histories.
