# STATIC FIELD 010 — THE LIVING WORLD ATLAS

**Review-only, offline-first, synthetic party-game experiment.** Stacks on Static Field Expansion Forge 009 draft exact source (PR #14) and preserves First Bell, Wormhole Wars, Living Deck, Little Yes Express 007, Earth Remembers 008, and the Forge 009 without merging or changing their authority. None of the game objects, player decisions, or crypto hashes assert real-world provenance, identity, ownership, labor consent, payment, work, or physical inventory.

## A world is a choice, not a broadcast

A *source table* runs real 007 game actions; Static Field's **actual 009 Forge** derives three finite, source-linked rule candidates. One portable offer bundles a privacy-minimized fictional history and one exact selected candidate. The content-addressed envelope is verified by reconstructing 009's source-owned Forge. No executable code is transported. The originating table does not get to activate that expansion in another table.

Each *receiving table* must decide separately: HOLD (default), REFUSE, or ADMIT. An admitted candidate starts a **fresh actual 007 railway game through 009's original `startVariant`**. A source history cannot donate game inventory, spent tokens, player consent, funding, validated engineering, proof, or authority. Each table may fork its own history, carry out actual 007 moves using 009 suggestions, and export newly generated proposals from its own play.

Two locally accepted worlds may also form a *constellation* — a real calculated AND condition across two independently playing original 009 objectives, not a pooled resource ledger or permission merge. A completed source-owned game can produce a new 010 offer for a different independent table.

## Play immediately

Open `index.html` in a modern browser. It is a self-contained HTML file, no CDN, account or external network. Three fictional tables come loaded:

- Porch Station prepares an expansion letter.
- Moon Lantern independently admits the exact same letter and forks the new world.
- Ash Orchard independently refuses it.

Choose a world and take the conductor's suggested action. Return a new expansion to the post office, select another receiving table, let that table admit or refuse, compose two locally accepted worlds into a constellation, export a JSON letter, or manually import one from a different browser. All local decisions stay independent, even when the content hash matches.

Run the original native modules and tests:

```sh
node --test experiments/little-yes-field-008/rail/game.test.mjs \
  experiments/little-yes-field-008/kingdom/kingdom.test.mjs \
  experiments/expansion-forge-009/tests/forge.test.mjs \
  experiments/living-world-atlas-010/tests/atlas.test.mjs
node experiments/living-world-atlas-010/build.mjs
node experiments/living-world-atlas-010/proof.mjs
```

The build script creates the single-file offline `index.html` using source modules. The CI workflow independently rebuilds that artifact twice and compares exact bytes, checks unit tests including native 007 and 009 tests, generates two copies of the proof packet, and compares them byte-for-byte. A downloadable local ZIP includes the historical 007–009 engines required to rebuild it.

## Proof boundary

- Validated on a *synthetic* three-table scenario: B admits; C refuses; B forks and completes a source-owned game objective; B sends a new source-derived packet back to A; A may admit; B makes a two-world constellation.
- External actor or network transport **not** implemented. Browser-only demo tables simulate separate receiver state; transporting the JSON by file is the real portable mechanism. Their IDs are unverified *labels*, not identities.
- The digest is SHA-256 **content integrity only**. An attacker can alter a packet and recompute the hash. Independent actors would need owner-issued signatures, trusted identity, and source-owned admission ports to establish authenticity.
- Source of 007 and 009 is actual included owner code. Groovetown 001–006, GrO, GHoT, planZ, CANNON, Full Measure, reLATTE, PENNY, and live Reality 2.0 are *not* invoked by this artifact.
- Local fictional world state is checked by replaying admitted source through actual 009 and all recorded moves; altered inventory, logs, or unsupported actions cannot be silently restored.
- Private unknown fields in a rail party record are stripped by the source-owned 009 minimizer. Fictional event text **is** exported: review it before deliberately sharing.
- No NFT or fiat issuance, human Deed, worker contact, physical action, genuine signatures, merge, hosting, or canonical admission. The UI does not make external requests. Human playtesting on actual devices remains required.
